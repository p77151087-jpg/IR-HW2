# 搜尋調整規格

確認與完成日期：2026-09-18。**狀態：已實作並完成驗證。** 依後續確認移除 COVID 別名表，改用通用邊界規則，索引升至 v5；全套 320 項測試通過，另完成本機真實語料與瀏覽器驗證。證據見 [成果紀錄](../reports/RESULTS.md#2026-09-18-通用詞彙匹配)。以下是現行已確認規格，取代先前「三種 COVID 寫法視為相同概念」的規定；這是使用者需求，不是教師新增的作業要求。

## 目標與現況

2026-09-19 補充：網頁固定啟用 Porter，移除開關與已保存的 stemming 設定；搜尋、排序、高亮一律使用 Porter 相關性索引。索引仍為 v5，不重建原文或索引；後端／CLI 參數保留相容性。此次驗證見 [固定 Porter 成果](../reports/RESULTS.md#2026-09-19-網頁固定啟用-porter)。

使用者輸入有意義的關鍵字，即可看到依相關性排序的文章；常見功能詞不應單獨產生大量結果，合理的詞彙變體應能互相找到。

| 項目 | 調整前 | 已完成行為 |
| --- | --- | --- |
| 搜尋介面 | 選擇 AND／OR／精準片語，再計分排序 | 移除這三個模式的選單，固定相關性搜尋 |
| 候選文章 | 依所選模式決定交集、聯集或片語命中 | 至少命中一個有效查詢條件，再計算分數；複合詞本身不拆成 OR |
| 停用詞 | 保留 `and`、`of`、`the` 等詞 | 自動過濾，不增加停用詞開關 |
| 單一字母 | 依一般 token 查找 | 對缺乏上下文的查詢給提示，保留有意義的生醫名稱 |
| 複合詞 | 曾用 COVID 專用別名表 | 以連字號及字母／數字交界處理所有詞；`covid` 可匹配 `COVID-19` 的部分，反向不自動放寬 |
| 排序與顯示 | 已有 TF-IDF cosine、相關性百分比 | 沿用公式，完整詞及有效部分成為不同特徵，百分比可能改變 |

完成流程：輸入 → 正規化、邊界分析與生醫字母保護 → 停用詞／資訊不足檢查 → 完整查詢條件 → 候選文章 → 相關性排序。

## 一、固定相關性搜尋

- 主畫面保留搜尋框、搜尋動作與結果，不再要求選擇 AND／OR／精準片語，也不把這三個選項移到新的進階選單。
- 多詞查詢允許部分符合。例如 `cancer treatment` 可以找出只有其中一個有效詞的文章，再依 TF-IDF cosine 排序；不再預設要求兩詞同時出現。
- 不把所有文章直接列出：候選文章必須命中至少一個有效條件，且有正的相似度。未知詞不產生候選；全部未知時顯示無結果。
- 保留「相關性：10%」這類整數百分比顯示，介面不以 TF-IDF 作結果欄位名稱。排序使用未四捨五入的分數，同分依文章編號穩定排序。
- 分數是詞彙向量相似度，不是相關機率或正確率。先不設定 10% 等任意最低門檻；正分數很低時，顯示值可能四捨五入為 0%，仍以原始分數排序。

## 二、停用詞與資訊不足的查詢

- 以隨專案保存、記錄來源與版本的保守英文停用詞表，過濾 `and`、`of`、`the` 及作為冠詞的 `a` 等低資訊詞。文件的搜尋表示與查詢端使用一致規則，計分也排除被過濾詞的影響。
- 先辨識需保留的生醫名稱，避免把 `vitamin A` 中的 A 當成冠詞刪除。首批至少涵蓋 `vitamin A/B/C`、`hepatitis B/C`、`B cell`、`T cell` 這類上下文；斜線在此表示多個名稱例子，不表示可任意刪除標點。
- 空白、純標點或過濾後沒有有效詞時，提示「請輸入具有主題意義的關鍵字」，不回傳整個文章庫。
- 情境保護與停用詞處理後，若剩下的查詢全部是孤立單字母，例如單獨的 `b`、`c` 或 `a b c`，提示「關鍵字過於簡短，請補充完整詞彙」。不以一律刪除所有單字母的方式處理。
- 生醫否定詞 `no`、`not` 預設保留為普通檢索詞。保留詞彙不代表已支援布林 NOT 運算或語意否定。

## 三、通用詞彙邊界與完整條件

- 移除搜尋別名表及 COVID 專用高亮分支。依 `-`／`‐`／`‑`、Unicode 字母／數字交界辨識組成部分；沿用 NFC、casefold、撇號及小數規則，沒有疾病名稱特例。
- 文件與查詢共用邊界分析及正規化；完整詞以 `-` 連接各部分，因此 `covid19`／`covid-19` 同為 `covid-19`，`IL6`／`IL-6` 同為 `il-6`，而 `covid` 保持 `covid`。
- 文件索引保存完整詞及有效單一組成部分；查詢每個 token 只保留完整條件，避免把 `HIV-1` 拆成「HIV 或 1」。因此 `covid` 可找 `COVID19`／`COVID-19`，但 `covid-19` 不找只有 `covid` 的文章。多個空白分隔關鍵字仍允許部分符合，如 `HIV-1 treatment` 可以因獨立的 treatment 命中另一篇文章。
- 同一特徵的同一原文位置不重複計 TF，真實不同位置仍累計；完整詞及部分屬不同特徵，分別計算 TF／DF 並進入文件向量範數。查詢依完整正規化條件去重，`IL6 IL-6` 不加倍權重；`covid covid-19` 則有兩個不同條件，不再宣稱等價。
- 每個特徵保存原文位置。搜尋 `covid` 只高亮 `COVID`，搜尋 `covid19`／`covid-19` 高亮完整 `COVID-19`；`risk` 只高亮 `high-risk` 的 risk。結果片段與內文使用相同位置，NFC／casefold 改變長度也不依正規化字串長度猜位置。
- 不支援任意子字串或前綴：`cov` 不會因為是 COVID 的開頭就命中它，但可以命中 `SARS-CoV-2` 的 CoV 部分。`HIV-1` 不等於 `HIV-2`，`BRCA1` 不等於 `BRCA2`。不跨空白、標點或區塊組合完整詞，不提供 CamelCase、任意連續部分組合或語意同義詞。

## 四、資料、統計與相容性

- 搜尋用詞彙表示獨立於原始文章及統計。摘要仍只計摘要正文，摘要單字數維持空白分隔口徑；全文統計、字元數、句數、讀取範圍均依原定義。
- 前處理為 `relevance-v2`，索引 v5；從本機文章重建索引、TF、DF 與文件向量範數，不混用舊資料，不重新下載 XML，也不重算文章統計。
- 新增、更新、刪除、還原文章及重新啟動後，仍須得到一致的索引與排序。網頁固定使用 Porter 且不提供開關，只對純 ASCII 字母特徵做詞幹還原；後端保留原詞／Porter 相容性，兩者皆套用一致邊界與過濾規則。
- 原始文字及位置資料可繼續供既有精準片語函式使用。舊後端／CLI 模式可先保留相容性，移除主畫面的模式選單不代表必須刪除全部舊函式。
- 透過引號啟用精準片語列為後續可選功能，本次不承諾新增引號解析、NOT／括號語法或進階模式選單。新預設搜尋不得把引號／布林字串當成已支援特殊語意來宣稱。

## 五、驗收

下列預期行為已由 `tests/test_relevance.py`、`tests/test_compound_search.py` 與相關回歸測試驗證。命中數以合成語料的獨立預期核對，真實文章另作展示，不把使用者可變動的文章庫篇數寫死。

| 案例 | 預期行為 |
| --- | --- |
| `the and of`、`a` | 無有效主題詞，提示補充關鍵字；不列出文章 |
| `b`、`c`、`a b c` | 提示補充完整詞彙；不列出文章 |
| `vitamin A`、`vitamin C`、`hepatitis B`、`T cell` | 保留名稱中的單字母，能參與匹配與計分 |
| `the treatment of cancer` | 與 `treatment cancer` 使用相同有效詞及分數 |
| `cancer treatment` | 能列入只有部分有效詞匹配的文章，依未四捨五入分數排序 |
| 原文只有 `COVID-19`，查詢 `covid`／`covid19`／`COVID-19` | 均能找到該文；`covid` 只高亮 `COVID`，另兩種高亮完整原詞；不保證廣泛詞與完整詞分數相同 |
| 原文只有 `covid`，查詢 `covid-19` | 不命中，完整條件保留 19 |
| `IL6 IL-6` | 正規化為同一完整條件，不重複加權 |
| `IL`／`BRCA`／`risk` | 可匹配 `IL-6`／`BRCA1`／`high-risk`，只高亮對應部分 |
| `HIV-1`／`BRCA1`／`H1N1` | 不匹配只有 `HIV-2`／`BRCA2`／`H1N2` 的文件 |
| `cat` 與只有 `education` 的文件 | 不作任意子字串搜尋，不命中 |
| 所有有效詞都不存在 | 清楚顯示無結果，不回退為整個文章庫 |
| `therapy`／`therapies` | 網頁自動合併詞幹，命中與排序一致，無需操作開關；高亮原文詞形 |
| 舊工作階段保存 `stemming=False` | 清除舊設定與過期結果頁／閱讀狀態，重新執行已提交查詢 |
| 新增／修改／刪除／還原／重啟 | 搜尋索引、文件頻率、分數及結果同步一致 |
| 介面、原文與統計 | 沒有 AND／OR／精準片語選單，相關性仍以百分比顯示；原文與統計定義保持一致 |

已完成手算完整詞／部分特徵 TF-IDF、TF／DF／查詢去重、Unicode 原文位置、HTML 安全、UI、v3／v4 升級與損壞修復、離線新程序及文章增刪還原驗證。完整回歸 320 項通過，四份 XML、文章快照與 manifest 雜湊不變，仍為 1,087 單字、53 句。目前 `covid` 命中三篇，原詞模式顯示 13%／10%／9%；`SARS` 命中四篇。[系統說明](SYSTEM.md)、[展示流程](DEMO.md) 及 [實測報告](../reports/RESULTS.md) 已同步更新。

## 六、課堂依據與範圍

已核對 2026-09-08 入門講義：第 30–41 頁介紹倒排索引及 AND，第 42–44 頁介紹布林運算與括號，第 32 頁示範分詞／詞形處理，第 50–52 頁介紹片語及排名。2026-09-15 應用講義第 32 頁列出 Tokenization 等 NLP 步驟，未規定唯一的字數算法。

作業單允許 stop-words 等前處理，未明確要求提供 AND／OR／精準片語模式選單，也未指定這些案例的唯一分詞方法。保留倒排索引、明確詞彙匹配及 TF-IDF 排序，仍可解釋其與課堂方法的對應；這不構成教師已核准或保證評分的聲明。

大規模生醫同義詞、向量語意搜尋、BM25、任意布林運算式及新引號語法均不列入本次已確認的實作範圍。
